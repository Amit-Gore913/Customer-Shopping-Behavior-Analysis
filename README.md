# Customer Shopping Behavior Analysis

## About the Project

I worked on this project to analyze customer shopping data and understand how customers purchase products, spend money, use discounts, and interact with subscriptions.

I used Python for data cleaning, MySQL for SQL analysis, and Power BI to create an interactive dashboard.

## What I Worked On

- Cleaned and prepared the customer shopping dataset using Python and Pandas
- Handled missing values and prepared the data for analysis
- Loaded the data into MySQL
- Wrote SQL queries to find useful business insights
- Created a Power BI dashboard to present the results

## Analysis Done

Some of the questions I explored were:

- Which gender generates more revenue?
- Which products have the highest average ratings?
- How do Standard and Express shipping compare?
- How does spending differ between subscribed and non-subscribed customers?
- Which products have more discounts?
- How can customers be divided into New, Returning, and Loyal customers?
- Which products are popular within each category?
- How much revenue comes from different age groups?
